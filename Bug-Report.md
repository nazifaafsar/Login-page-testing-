# Bug Report

## Bug 1: Login with Invalid Password

**Bug ID:** BUG001

**Title:** Error message should be displayed for invalid password

**Steps to Reproduce:**
1. Open the login page.
2. Enter a valid username.
3. Enter an invalid password.
4. Click the Login button.

**Expected Result:**
An appropriate error message should be displayed.

**Actual Result:**
The system should not allow the user to login with an invalid password.

**Severity:** Medium

**Priority:** High

**Status:** Open
