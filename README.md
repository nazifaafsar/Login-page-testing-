
# Login Page Manual Testing Project

## Project Overview
This project demonstrates manual testing of a sample login page.

## Testing Objective
To verify that the login page works correctly according to the requirements.

## Test Scenarios
1. Verify login with valid username and password.
2. Verify login with invalid username and password.
3. Verify login with empty username and password.
4. Verify password field is masked.
5. Verify the login button works correctly.

## Testing Type
- Manual Testing
- Functional Testing
- Positive Testing
- Negative Testing

## Tools Used
- GitHub
- Manual Testing
